# Workflow 运行详情轻量浮层

## 目标

把 Workflow 图上的运行详情从信息堆叠的大卡片改成紧凑的轻量浮层。实时输出始终是视觉重点，输入、输出和运行记录按需查看，不遮蔽关键状态与操作。

## 布局

- 保留右侧浮层位置与现有关闭交互，收轻边框、阴影、圆角和内边距。
- 顶部集中显示节点名称、执行次数、耗时与中文状态。
- 实时输出紧接标题，以一块浅色强调区域持续展示等待状态或 Runtime 文本。
- 输入、输出和运行记录使用三个原生折叠区，默认全部折叠；标题行同时展示数量或当前摘要。

## 状态与操作

- 运行、暂停、完成、失败和取消继续使用现有 Run 状态，不改变执行逻辑和流式数据链路。
- 执行错误与重试按钮直接显示，不折叠。
- Approval 节点的待确认选项直接显示，不折叠。
- 切换节点后，新的详情浮层重新以默认折叠状态展示。

## 视觉

沿用应用已有颜色、字体与间距变量，不引入新的视觉体系。浮层只保留一层容器；实时输出是唯一强调面，其余信息使用分隔线和摘要行组织，不再嵌套卡片。

## 验证

- 保留并更新现有 UI 回归测试，确认运行中的 Agent 在首个 delta 前仍能看到实时输出。
- 运行 TypeScript 检查和 Workflow 流式输出相关测试。
- 在 V2 实际运行 Workflow，人工确认折叠区、错误/Approval 可见性与整体视觉效果。
- 按用户要求，不为默认折叠或点击展开行为新增自动化测试。
