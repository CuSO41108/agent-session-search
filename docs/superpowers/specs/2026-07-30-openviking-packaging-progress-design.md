# OpenViking 打包进度显示设计

## 目标

开发版首次构建 OpenViking 运行包时，打包阶段展示真实的已生成大小和生成速度，让用户能判断安装仍在推进。

## 行为

- 打包开始后，每 500ms 读取临时压缩包当前大小。
- 进度事件沿用现有 `packaging-runtime` 阶段，通过 `downloadedBytes` 和 `bytesPerSecond` 传递数据。
- 页面显示“已生成 X MB · Y MB/s”，并保留不确定进度条。
- 压缩包最终大小无法提前准确获知，因此不显示估算百分比或虚构总大小。
- 打包完成时再发送一次最终大小，确保界面展示准确结果。

## 边界与错误处理

- 第一次读取时文件可能尚未创建，此时按 0 字节处理。
- 读取文件大小失败不能中断打包；只跳过该次进度刷新。
- 定时器必须在成功或失败时清理，不能遗留后台任务。
- 正式版下载运行包的既有百分比和下载速度展示保持不变。

## 验证

- 脚本测试验证打包阶段会发送递增的真实字节数和速度。
- UI 测试验证无总大小时显示已生成大小，不显示百分比。
- 运行 OpenViking、类型检查、完整测试与应用构建。
