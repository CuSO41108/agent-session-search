# AgentRecall v2 使用指南

[返回项目首页](../../README.md)

AgentRecall v2 是开发版，包含工作台、Session、多 Agent Chat、Workflow、Eval、Runtime、MCP、目录记忆和 Skill 库。

v2 使用独立的命令、应用数据和数据库，可以和 v1 同时运行，但不会自动读取或导入 v1 数据。

## 1. 安装与首次启动

AgentRecall v2 需要 macOS 或 Windows，以及 Node.js 22.13 或更高版本。当前从源码启动：

```bash
git clone https://github.com/zszz3/AgentRecall.git
cd AgentRecall
npm run setup:v2
npm run dev:v2
```

后续启动只需在仓库根目录运行：

```bash
npm run dev:v2
```

v2 目前不使用 v1 的 Release 安装包和自动更新通道。拉取新代码后，如果依赖有变化，再执行一次 `npm run setup:v2`。

首次打开后：

1. 在 **Runtime** 中检查可用的执行配置，并创建之后要在 Chat、Workflow 或 Eval 中使用的 Agent。
2. 进入 **设置 → 可选来源**，开启需要索引的其他 Agent。Claude Code 和 Codex 默认启用。
3. 打开 **Session** 并点击 **更新索引**，等待本机会话载入。
4. 如需 AI 摘要或自然语言找会话，在 **Provider** 中选择使用 Codex、Claude Code 或自定义接口。

应用启动后会常驻菜单栏或系统托盘。全局唤起快捷键、默认终端、主题和语言都可以在设置中调整。

## 2. 工作台

应用默认打开 **工作台**。这里把常用信息和入口放在同一页：

- 会话数、消息数、Token 用量、缓存率和来源分布。
- Claude Code、Codex 的模型额度。
- 最近或正在进行的会话。
- 最近的 Workflow 和 Chat 工作室。
- 已管理的 Memory 目录。
- Runtime、MCP 和 Skills 的当前状态。

### 搜索和打开会话

在会话卡片中输入关键词并按 Enter，会跳转到 Session 页面显示完整结果。点击最近会话可以查看详情，来源支持 Resume 时也可以直接继续。

### 调整卡片顺序

点击右上角的 **调整布局**，拖动卡片改变顺序，也可以使用卡片上的前移、后移按钮。点击 **完成**退出编辑。顺序会保留在当前设备上。

### 用量和额度

用量可以切换今天、7 天、30 天和全部时间。点击趋势中的某一天，会进入 Session 页面查看当天会话。

额度卡片显示当前可取得的 Claude Code 和 Codex 额度。某张卡片不需要时，可以在设置中隐藏。

## 3. Session

Session 页面负责索引、搜索、查看和整理不同 Agent 的历史会话。

### 会话来源

| 类型 | 包含的来源 |
| --- | --- |
| 默认来源 | Claude Code CLI、Claude Desktop、Codex CLI、Codex Desktop |
| 可选来源 | CodeBuddy、CodeWiz、TClaude、TCodex、OpenClaw、Hermes、OpenCode、ZCode、Cursor Agent、Trae、Qoder |
| 扩展环境 | SSH 远程环境、Windows WSL |

可选来源需要先在 **设置 → 可选来源** 中开启，再点击 **更新索引**。不同来源支持的 Resume、迁移、删除、同步和统计能力可能不同，页面只会显示当前可用的操作。

### 搜索和筛选

在 Session 页面按 `Cmd+F`（macOS）或 `Ctrl+F`（Windows）聚焦搜索框。输入关键词后按 Enter，结果会显示标题、项目和命中的消息片段。

还可以使用：

- 左侧的环境、项目、来源、收藏和隐藏视图。
- 顶部的时间范围、状态和排序。
- 最近搜索记录。
- 高级搜索条件、保存的搜索和结果分组。
- **AI 找会话**，用自然语言描述想找的内容。

### 查看和整理

点击结果打开会话详情。详情页显示完整消息、Markdown、代码块、工具事件、附件和 AI 摘要。

在详情页按 `Cmd+F` 或 `Ctrl+F` 查找当前会话。Enter 跳到下一个结果，Shift+Enter 返回上一个。

会话支持重命名、添加标签、收藏和隐藏。右键菜单和详情页会提供当前来源可用的 Resume、迁移、导出或删除操作。

### Resume、迁移和导出

Resume 会使用设置中的默认终端打开原会话。也可以复制命令后手动运行。

迁移时选择目标 Agent 和项目目录。目标是可选来源时，需要先在设置中开启。迁移会创建新的目标会话，不会覆盖原会话。

导出支持 Markdown、纯文本，以及 OpenAI Chat、OpenAI Responses 或 Anthropic 请求格式的 JSON。模型请求 JSON 可能包含完整提示词、工具参数和回复，请保存在可信目录中。

### 远程环境和跨设备同步

在 **设置 → 连接** 中添加 SSH 主机；Windows 还可以添加 WSL 发行版。连接通过后，远程项目会显示在 Session 左侧。

点击云朵图标打开会话同步。配置自己的 Supabase 项目后，可以手动上传会话、查看同步状态、搜索云端会话、恢复到当前设备或删除云端副本。

本地和云端都发生变化时会显示内容冲突。批量上传会跳过冲突，只有明确选择覆盖时才会更新云端。恢复总是创建新的本地副本，删除云端副本不会删除本地会话。

## 4. Chat

Chat 用于让多个独立 Agent 在同一个项目目录中协作。使用前，先在 **Runtime** 页面创建至少一个 Agent。

### 创建工作室

点击 **新建房间**，填写：

- 房间名称。
- 可选的工作目录。
- 参与的 Agent。
- 每名 Agent 在房间中的显示名称。

每名 Agent 会保留自己的独立会话。可以重复添加同一种 Runtime，让它们承担不同角色。

### 发送消息

不带 `@名称` 的内容只会写入房间，不会唤醒 Agent。需要某个 Agent 处理时，可以：

- 在输入框中输入 `@名称`。
- 从 **发送给**区域选择一个或多个成员。
- 点击成员，在本轮中把它设为接收者。

回复会按 Agent 分开展示。正在生成时可以停止本轮。

### 管理房间和 Agent

- 修改房间标题。
- 为已有房间添加 Agent。
- 让某名 Agent 开始新会话。
- 查看 Agent 使用持续会话还是每次创建新上下文。
- 归档不再使用的工作室。
- 永久删除工作室及其 Chat 数据。

归档适合暂时隐藏；永久删除前请确认房间中是否还有需要保留的内容。

## 5. Workflow

Workflow 用于把一个任务拆成可重复运行的 Agent 或脚本节点，并保留每次运行的状态和产出。

### 创建工作流

点击 **新建 Workflow**，输入任务描述。Workflow Agent 会继续提问，以确定目标、输入、输出和节点关系。完成后会生成工作流图。

运行前可以：

- 选择工作目录。
- 选择负责生成工作流的 Agent 和模型。
- 为单个节点指定 Agent。
- 查看和编辑节点图。
- 使用独立 Reviewer 检查阻塞问题、脚本风险和改进建议。
- 确认当前工作流版本。

### 运行和干预

确认工作流后点击 **运行工作流**。页面会显示节点状态、输入来源、执行 Agent 和产出。

运行期间可能需要你：

- 回答节点追问。
- 确认或拒绝脚本权限。
- 暂停、继续或停止节点。
- 接受或拒绝节点的完成结果。
- 在失败后选择继续、回滚到保存点、保留现场或放弃恢复。

页面会自动打开需要处理的节点。完成后可以查看主 Agent 总结、节点消息、登记产物和输出文件。

### 运行历史

打开 **运行历史**可以按状态、触发来源、图版本和时间筛选。每次运行会保留只读快照，包括节点时间线、消息、输入、输出、Token 用量和产物。

如果运行停在恢复状态，历史详情会显示当前可以执行的恢复动作和冲突处理入口。

## 6. Eval

Eval 用于比较 Agent 在固定任务上的输出，持续查看质量变化。

### 数据集

数据集保存可重复使用的输入和期望结果。创建后可以增加、修改或删除 Case。

### 评估器

评估器负责判断结果是否通过。可以配置确定性规则，也可以选择独立的 LLM Judge。模板菜单提供常用评估方式的起点。

### 实验

实验把数据集、Agent 和评估器组合在一起。保存后点击运行，结果会记录：

- 每个 Case 的得分和通过状态。
- 实验平均得分和通过率。
- 失败原因。
- 最近运行记录。

**质量概览**会汇总数据集、启用的评估器、平均得分、通过率和最近失败 Case。

## 7. Runtime

Runtime 管理执行配置和可复用 Agent。Chat、Workflow、Eval 和 MCP 都会使用这里保存的配置。

### 执行配置

在 **执行配置**中可以：

- 新建或导入本机已有配置。
- 选择执行器和 Provider。
- 添加、删除或刷新模型。
- 配置需要的插件。
- 测试连接。
- 在支持的 Provider 上查询余额。

修改后点击 **保存**。切换页面时如果有未保存内容，应用会先提示。

### Agent

在 **Agent**页创建可复用 Agent，并选择：

- 使用哪个执行配置。
- 默认模型。
- 显示名称和用途说明。
- 会话是否持续复用。

Chat 工作室、Workflow 节点和 Eval 实验会引用这些 Agent。删除或修改前，先确认其他页面是否仍在使用。

## 8. MCP

MCP 页面管理 v2 Agent 可以使用的工具服务。

### 服务器

点击 **新建 MCP Server**，选择传输方式：

- **STDIO**：填写启动命令、参数和需要的环境变量。
- **HTTP**：填写远程服务地址和连接配置。

保存前可以测试连接。连接成功后会显示服务提供的工具；不再使用的服务器可以删除。

### Agent 绑定

切换到 **Agent 绑定**，选择目标 Agent，再开启需要的 MCP Server。绑定后的服务会用于该 Agent 的新会话。

Codex Agent 还可以从托管目录安装部分常用服务。目录中的服务可能要求选择允许访问的文件夹或填写对应 Token。API Agent 当前不支持 MCP 绑定。

AgentRecall 自身的会话检索 MCP 仍在 **设置 → AI** 中管理。它让外部 Agent 搜索和整理 AgentRecall 会话，与本页为 v2 Agent 配置工具服务是两个入口。

## 9. Memory

Memory 为不同项目目录建立相互隔离的长期记忆。该功能默认关闭。

### 完成准备

进入 **设置 → Memory**：

1. 启用目录记忆。
2. 按页面提示准备 Memory Runtime。
3. 选择或安装本地向量模型。
4. 确认运行状态正常。

首次准备可能需要下载额外运行文件和模型。

### 管理目录

打开 Memory 页面，点击 **添加目录**。确认后，v2 会把该目录加入管理，并导入已经索引到的历史会话。

导入期间可以暂停或继续。目录移动后可以重新关联。每个目录的会话、记忆和索引相互隔离。

### 使用记忆

选择目录后可以：

- 搜索已有记忆。
- 查看记忆详情。
- 新建、修改或删除手动记忆。
- 查看从历史会话生成的只读记忆。
- 停止管理目录，但保留已有数据。
- 删除该目录在 Memory 中的数据。

需要让 Agent 自动使用这些记忆时，在设置中为 Codex、Claude Code 或 OpenCode 开启召回。只为确认过的项目目录启用，避免把一个项目的内容带进另一个项目。

## 10. Skills

Skills 页面分为 **本 App Skill**和**本地 Skill**。

### Skill 库

本 App Skill 是加入 AgentRecall Skill 库的内容。可以查看详情、选择目标 Agent 安装、更新或从库中删除。

点击 **发现 Skill**可以：

- 按关键词搜索 skills.sh。
- 描述想解决的问题，让 AI 匹配 Skill。
- 查看安装量、说明和匹配原因。
- 把选中的 Skill 加入本 App Skill 库。

加入 Skill 库不会自动安装到 Agent。查看内容并选择目标后，再执行安装。

### 本地 Skill 与同步

本地 Skill 页面显示当前设备上已安装的 Skills。可以搜索、按来源筛选、预览 `SKILL.md`、打开目录和查看使用次数。

配置自己的 Supabase 项目后，可以上传符合条件的本地 Skill，并在另一台设备安装或更新。系统、项目或插件管理的 Skill 可能不会显示上传入口。

## 11. Provider、同步与设置

### Provider

Provider 页面分别管理：

- Codex 使用官方认证还是自定义 OpenAI-compatible 接口。
- Claude Code 使用官方认证还是自定义 Anthropic-compatible 接口。
- AI 摘要与搜索使用 Codex、Claude Code 还是单独的自定义接口。

自定义 Codex Provider 可以探测接口返回的模型，也可以手动输入模型名。保存时可以只保留在 AgentRecall 中，确认后再写入 Codex 或 Claude Code 配置。

### 远程同步和数字资产

会话同步、Skills、Rules 和 Memories 可以使用你自己的 Supabase 项目。相同配置放到另一台设备后，可以恢复会话或数字资产。

点击顶部的云朵图标管理会话，点击数据库图标管理 Rules 和 Memories。删除云端副本不会自动删除本地内容。

### 常用设置

- **默认终端**：选择 Resume 使用的终端。
- **全局快捷键**：修改系统级打开窗口快捷键，并查看应用内快捷键。
- **连接**：管理 SSH 和 WSL。
- **可选来源**：启用 Claude Code、Codex 之外的来源。
- **AI**：管理摘要、AI 找会话和 AgentRecall 会话检索 MCP。
- **远程同步 / Skills**：配置 Supabase。
- **Memory**：准备目录记忆的 Runtime、模型和自动召回。
- **外观**：切换主题、语言和 Dock 显示方式。

v2 仍是开发版。更新代码时使用 Git 拉取仓库改动，再按需要重新执行 `npm run setup:v2`。
