# Workflow 结构化编排

## 新增功能

- Workflow 现已使用结构化的目标、指令、约束、输入引用、输出字段和完成标准，可组合 Agent、Script、Review 与 Approval 节点；所有节点共享当前工作目录，并可在运行时查看实际输入、校验结果和错误。
- 模板库内置“简历近期技术亮点补充”“代码变更审查”“基于现有代码生成技术方案”和“发布前检查”四套只读模板，可预览流程图并复制为自己的可编辑 Workflow。
- Workflow 启动后可查看当前节点、整体进度、耗时、节点活动记录与 Agent Runtime 流式输出，并可暂停、继续或取消正在执行的 Run。
- Workflow Run 的 Agent 过程会按执行步骤自然分段并默认优先使用中文；节点输入和输出会按段落、列表与属性展示，不再显示为大块 JSON 数据。
- MCP 页面现在明确区分项目内置与自定义服务，并用可读名称和用途展示会话检索与 Workflow 两个内置 MCP。

## Bug 修复

- Workflow 可正确接收 Agent 在说明文字中返回的结构化结果，不再因 JSON 代码块前后带有补充说明而错误判定运行失败。
- 修复 Workflow 运行详情中字段键名与状态信息字号异常偏大的问题，使辅助信息保持轻量、不再抢占正文视觉层级。
