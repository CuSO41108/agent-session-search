# Agent 可按需读取已管理的 Skill
<!-- release-target: v2 -->

## 新增功能

- ✨ MCP 页新增独立的 AgentRecall Skill 项目内置服务，可列出已管理的 Skill，并按需读取具体内容。
- ✨ AIHOT 资讯查询 Skill 现已随 AgentRecall 内置，可直接在 Skill 页面安装到支持的 Agent。
- ✨ 简历优化 Skill 现已随 AgentRecall 内置，支持中英文说明并可直接安装到支持的 Agent。

## Bug 修复

- 🐛 AgentRecall 会话检索与 Workflow MCP 的工具说明现已统一为中文。
- 🐛 Workflow MCP 默认目录精简为 6 个核心只读工具，内部规划与执行能力继续按作用域提供。
- 🐛 AgentRecall 会话检索 MCP 移除低价值的项目和标签枚举工具，保留搜索参数中的项目筛选能力。
