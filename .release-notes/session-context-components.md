# 会话详情查看上下文构成

<!-- release-target: both -->

## 新增功能

- ✨ 打开 Codex / Claude 会话详情时，可在 AI 摘要下方展开「上下文构成」：Codex 可查看系统提示词、Developer 提示词（非用户提示词）和工具清单；Claude 在有记录时可查看 Skills / MCP / 延迟工具 / Agent 等清单。默认折叠，仅展示能从本地会话文件提取到的信息。

## Bug 修复

- 🐛 修复展开「上下文构成」后一直停在「加载中…」的问题；现在会正常显示结果，失败时也会给出错误提示。
- 🐛 修复「上下文构成」各模块过高、滚到 Developer 提示词后看不到后续分段的问题；全文区块更矮，详情面板可继续向下滚动到工具清单等内容。
- 🐛 修复 Codex 会话「上下文构成」经常只有系统 / Developer 提示词、看不到工具清单的问题；现在会从本会话实际 tool call 反推工具名（含 MCP）。
