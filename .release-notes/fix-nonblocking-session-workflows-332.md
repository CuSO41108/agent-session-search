# 改善启动和会话任务响应速度

<!-- release-target: both -->

## Bug 修复

- 单条本地或远程环境会话读取失败时，云端同步列表仍可加载其余会话；刷新后也不会继续显示已经失效的初始化提示。
- 修改或清空 Supabase 连接配置后，会话同步会丢弃旧连接的错误和列表，下次打开时按新配置重新加载。
- CodeWiz 会话不再因为云端类型校验遗漏而批量上传失败。
- 云端会话数量较多时，同步列表不再因为一次读取过多搜索内容而超时。
- SSH 会话原文件丢失时，已有完整缓存的对话仍可上传；只有摘要的失效记录不再反复上传失败。
- 应用启动后不再因后台检查全部历史会话而短暂卡住，主界面可以更快开始操作。
- 从设置打开会话同步时，窗口会先立即响应，再以轻量方式核对本地与云端状态；历史会话较多或单条会话很大时不再卡住应用。首次加载也可转到后台并收到明确确认，再次打开会沿用已有结果，加载完成后不再残留加载提示。
- 会话列表已展开较多内容时，切换来源、状态、排序或环境不再重复渲染旧列表；索引完成后的列表、环境和用量刷新也不会叠加卡住应用。
- 环境中项目很多时，侧边栏会分批显示项目，并保留当前选中的项目；首次打开和切换环境不再一次渲染全部项目而卡住界面。
- 体积较大的 Codex App 会话会分段读取和建立索引，扫描期间仍可切换筛选、查看用量和打开设置。
- 工作台的 Codex 与 Claude Code 额度信息会与中间分隔线保持舒适间距，不再紧贴边界。
